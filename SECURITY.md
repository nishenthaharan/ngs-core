# Security policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not
open a public issue containing exploit details, credentials, human genomic data, or other
sensitive material.

Include the affected version, operating system, smallest reproducible input, impact, and
any proposed mitigation. Synthetic sequencing data is strongly preferred.

## Data handling

NGS Core runs locally and does not transmit reads. Users remain responsible for access
control, encryption, retention, and deletion policies appropriate to their datasets and
jurisdiction.
